# Security policy

## Supported versions

| Version | Supported |
| --- | --- |
| 0.1.x (the `v0` tag) | yes |

## Reporting a vulnerability

Use the Security tab on this repository and choose **Report a vulnerability**. That opens a [private advisory](https://github.com/omsocll/proofslip/security/advisories/new). Do not send the report by email, and do not open a public issue for it.

Do not paste a token, key, password, or other secret into an issue, pull request, or commit. Name the file, commit, or workflow where it appeared. If a credential is in the git history, say so and leave the history as it is. Rewriting history does not revoke the credential.
